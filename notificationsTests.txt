
1. Basic Notification Scheduling:
   - Schedule a notification for an upcoming event
   - Verify the notification appears in the list
   - Check that the countdown timer starts correctly

2. Multiple Notifications for One Event:
   - Schedule multiple notifications for the same event (e.g., 1 hour, 30 minutes, and 5 minutes before)
   - Verify all notifications appear in the list
   - Ensure each has a unique countdown

3. Notifications for Multiple Events:
   - Schedule notifications for different events
   - Verify all appear correctly in the list
   - Ensure they're sorted by trigger time

4. Custom Time Input:
   - Use the custom time input to set a notification
   - Verify it's added correctly with the exact time specified

5. Duplicate Prevention:
   - Try to schedule the same notification twice
   - Verify you receive an error message
   - Check that no duplicate is added to the list

6. Notification Triggering:
   - Wait for a notification to trigger
   - Verify you receive a Chrome notification
   - Check that it's removed from the list after triggering

7. Manual Notification Removal:
   - Remove a scheduled notification manually
   - Verify it disappears from the list
   - Ensure no ghost notifications remain

8. Expired Notification Handling:
   - Set the system clock forward to make a notification expire
   - Verify it's automatically removed from the list

9. Browser Restart Persistence:
   - Schedule some notifications
   - Close and reopen the browser
   - Verify all scheduled notifications are still present

10. Popup and Background Sync:
    - Open the popup
    - Make changes (add/remove notifications) from another tab
    - Verify the popup updates in real-time

11. All Notifications Page:
    - Open the "View All Notifications" page
    - Verify it shows all scheduled notifications
    - Check that countdowns update in real-time

12. Long-term Notifications:
    - Schedule a notification for a very distant future event (e.g., 1 year from now)
    - Verify it's added and persists after browser restarts

13. Short-term Notifications:
    - Schedule a notification for the very near future (e.g., 1 minute from now)
    - Verify it triggers correctly and on time

14. Simultaneous Notifications:
    - Schedule multiple notifications to trigger at the same time
    - Verify all trigger correctly and are removed from the list

15. Network Changes:
    - Schedule notifications while online
    - Disconnect from the internet
    - Verify notifications still trigger when offline

16. System Sleep/Hibernate:
    - Schedule notifications
    - Put the system to sleep or hibernate
    - Wake the system and verify notifications trigger correctly

17. Daylight Saving Time Changes:
    - Schedule notifications spanning a DST change
    - Verify they trigger at the correct wall clock time

18. Timezone Changes:
    - Schedule notifications
    - Change the system timezone
    - Verify notifications adjust and trigger correctly

19. Extension Update:
    - Schedule notifications
    - Update the extension to a new version
    - Verify all scheduled notifications persist and function correctly

20. Large Number of Notifications:
    - Schedule a large number of notifications (e.g., 100+)
    - Verify the system remains responsive
    - Ensure all notifications are managed correctly

21. Event Cancellation:
    - Schedule notifications for an event
    - Simulate the event being cancelled
    - Verify all related notifications are removed

22. Event Time Change:
    - Schedule notifications for an event
    - Change the event time
    - Verify notifications adjust accordingly

23. Notification Sound and Display:
    - Trigger a notification
    - Verify the correct sound plays (if applicable)
    - Check that the notification display includes all necessary information

24. Notification Click Behavior:
    - Trigger a notification
    - Click on the notification
    - Verify it opens the correct event page or takes the appropriate action

25. Permission Changes:
    - Revoke notification permissions for the extension
    - Verify the system handles this gracefully
    - Re-enable permissions and check functionality resumes

Polyteller Extension Comprehensive Testing Plan

1. Event Information Extraction
   - Test extraction from various Polymarket page layouts (single event, multiple events, different UI versions)
   - Verify handling of different date/time formats (12h/24h, various locales)
   - Test with events in different timezones (UTC, EST, PST, etc.)
   - Edge case: Test with malformed event data (missing fields, incorrect formats)
   - Test extraction of event details (title, description, odds, etc.)
   - Verify handling of events with no end date or "TBA" end dates
   - Test with events that have been updated or modified on Polymarket
   - Test with different market types (binary, scalar, multiple choice)
   - Test extraction during market state changes (resolved, paused, etc.)
   - Verify handling of markets with multiple resolution dates
   - Test with markets having conditional resolution dates

2. Countdown Functionality
   - Verify accuracy of countdown on page and in popup (compare with system time)
   - Test countdown behavior across midnight, date changes, and month/year transitions
   - Edge case: Test with events ending in less than a minute
   - Edge case: Test with very long-term events (e.g., years in the future)
   - Verify countdown updates in real-time without page refresh
   - Test countdown display formatting (days, hours, minutes, seconds)
   - Verify countdown behavior when switching between tabs/windows
   - Test countdown accuracy after system sleep/hibernate
   - Test countdown behavior during browser minimize/maximize
   - Verify countdown accuracy with different performance.now() precision
   - Test countdown sync between popup and content view
   - Verify memory usage during long-running countdowns

3. Notification Scheduling
   - Test scheduling notifications at various intervals (minutes, hours, days before event)
   - Verify notifications trigger at correct times
   - Test scheduling multiple notifications for one event
   - Edge case: Test scheduling notification for past time
   - Edge case: Test maximum number of notifications per event
   - Verify notification scheduling across browser sessions
   - Test rescheduling notifications when event time changes
   - Verify handling of conflicting notifications (same time, different events)
   - Test notification scheduling near daylight saving time transitions

4. Alarm Management
   - Verify alarms are created correctly in Chrome
   - Test alarm triggering and notification display
   - Edge case: Test behavior when Chrome is closed/reopened
   - Edge case: Test with system time changes (forward and backward)
   - Verify alarm persistence across browser restarts
   - Test alarm behavior when multiple events end simultaneously
   - Verify alarm cleanup for expired or cancelled events
   - Test alarm rescheduling when event times are updated
   - Test alarm behavior during system hibernation/resume
   - Verify alarm priority handling when multiple alarms trigger simultaneously
   - Test alarm persistence during extension updates
   - Verify alarm cleanup during tab/window closure

5. State Persistence
   - Verify event data and notifications persist after browser restart
   - Test data sync between background and popup
   - Edge case: Test with Chrome storage quota exceeded
   - Verify state consistency across multiple tabs/windows
   - Test state recovery after extension update
   - Verify handling of corrupted state data
   - Test state persistence during and after system crashes

6. Timezone Handling
   - Test events and notifications across different timezones
   - Verify correct timezone conversion and display
   - Edge case: Test during Daylight Saving Time transitions
   - Test with users changing their system timezone
   - Verify handling of events in timezones with fractional hour offsets
   - Test display of multiple events from different timezones
   - Verify timezone abbreviation display and accuracy
   - Test behavior during rare timezone changes (e.g., Venezuela, North Korea)
   - Verify handling of ambiguous times during DST transitions
   - Test with markets spanning DST changes
   - Verify timezone abbreviation display accuracy

7. User Interface
   - Test responsiveness of popup UI on various screen sizes
   - Verify all UI elements are functional (buttons, dropdowns, toggles)
   - Test custom notification time input (validation, edge cases)
   - Edge case: Test with very long event titles and descriptions
   - Verify UI updates in real-time (countdown, notifications)
   - Test UI performance with a large number of events/notifications
   - Verify proper error message display for various scenarios
   - Test UI behavior when rapidly switching between events

8. Trade Confirmation Popup
   - Verify toggle functionality in settings
   - Test appearance and behavior of confirmation popup
   - Edge case: Test with rapid trade attempts
   - Verify confirmation popup doesn't interfere with other site functionality
   - Test trade confirmation with various trade amounts and types
   - Verify proper handling of cancelled confirmations
   - Test confirmation popup on different Polymarket page layouts
   - Test confirmation dialog positioning on different screen sizes
   - Verify keyboard focus management in dialog
   - Test dialog behavior during rapid market price updates
   - Verify dialog cleanup after trade execution/cancellation

9. Performance
   - Test with multiple Polymarket tabs open (20+)

   - Edge case: Test CPU and memory usage over extended periods (24+ hours)
   - Measure and optimize extension load time
   - Profile background script performance

   - Verify performance on low-end devices
   - Test CPU usage during rapid tab switching
